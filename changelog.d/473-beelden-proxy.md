- Laad artikelfoto's via de eigen beeldproxy `/media/beeld/<host>/…` (Pages Function met vaste hostallowlist) zodat uitgevers geen cookies van derden meer zetten; Lighthouse best practices herstelt (#473). De proxy kiest het formaat op de `Accept` van de bezoeker (avif/webp/basis, `Vary: Accept`), cachet alleen geslaagde antwoorden per emmer in de Cache API (randcache van de upstream-fetch uit) en de browser valt terug op de rechtstreekse URL als de proxy faalt.
- Beeldproxy: antwoorden zijn `private` voor de gedeelde randcache (geen vermenging van avif/webp/jpeg tussen bezoekers) en `.png`-beelden lopen weer via de Function (`_routes.json` sluit nu exacte bestanden uit in plaats van `/*.png` e.d.) (#473).
